# 🚨 ResQNet - Real-time Emergency Response & Resource Allocation Platform

ResQNet is a full-stack disaster management and emergency response platform designed to connect victims in need with nearby relief centers, NGOs, and volunteers in real time.

---

## 🔥 Key Features

* **🚨 SOS Alert Trigger:** Victims can instantly broadcast emergency requests (Medical, Food/Water, Rescue) along with location details.
* **⚡ Active Emergency Feeds:** Real-time visibility of urgent help requests for responders, volunteers, and admin teams.
* **📍 Nearby Available Resources:** Geospatial mapping ($near MongoDB query) that displays relief inventory (Food, Water, Supplies) within a 10km radius.
* **🤝 Multi-tier Responder Ecosystem:** Coordinates support from local individual volunteers, NGOs, private organizations, and official government rescue teams.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (Fetch API, Dynamic Dashboard UI)
* **Backend:** Node.js, Express.js
* **Database:** MongoDB (Mongoose ORM)
* **Authentication:** JWT (JSON Web Tokens)
